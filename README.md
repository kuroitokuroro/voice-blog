こちらは、毎日を管理できる手帳ツールです。

タイトル：こえ手帳
ジャンル：声で自己管理するオールインワンな手帳ツール
推奨環境：Android　Chrome
進捗：もう使える　改良中

▼このアプリのターゲット層

・スマホのし過ぎで指が疲れて、文字入力が億劫な人
・声に出すことで、自分の記憶にも予定を残したい人
・習慣や予定のアプリに日付を入力するのがめんどくさい人

・視力に難がある人（将来的にはターゲット？）

予定タブでは、先頭に数字4文字を入力することで日付として認識し、自動で並び替える機能があります。
